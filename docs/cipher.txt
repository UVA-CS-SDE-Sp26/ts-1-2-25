Cipher Documenation (Team Member D - Aiden Menefee yxs8gt) Design and Test plan

Design:
1 Purpose
  - This component will be responsible for deciphering text.
  - It will take in a ciphered string and return a deciphered (readable) string
  - It will not print anything
  - It does NOT open or read the .txt files in data/
  - Idea: take text + a key and return text (or error)
2 Cipher Key file information
  - The default cipher key is stored in: ciphers/key.txt
  - This file must contain at least two lines (it uses the first two):
    - Line 1: the actual (real) characters
    - Line 2: the cipher characters
  - These characters will be matched by positions
    - For example: the character at index i in line 2 will map to character at index i in line 1
3 Validating the cipher key (crucial step before deciphering)
  - After the cipher key is loaded:
    - Check that the file exists and can be read
    - Check that the first two lines exist
    - Check that both lines are the same length
    - If any of these checks fail, return an error
4 How the deciphering will work at a high level
  - Load and validate the key
  - For each of the characters in the ciphered input text
    - If the character appears in the cipher line
      - Find its index
      - Replace it with the character at the same index in the real line
    - Else 
      - Leave the character unchanged
  - Return the fully deciphered string
5 Errors
  - If file missing or invalid, return an error string to program control
  - If deciphering cannot be performed, return an error
  - Program control will handle displaying the error and exiting the program

Testing plan:
1 Run key validation tests:
  - Check if valid key file passes validation process
  - Check if missing key file causes a failure
  - Check if key file with fewer than two lines causes a failure
  - Check if key file with unequal line lengths will cause a failure
2 Run decipher tests:
  - Check if a known ciphered input produces a expected, readable output
  - Check if spaces, punc, newlines etc are preserved in an input
  - Check if an empty input returns and empty string
  - Check if the decipher fails properly when an invalid key is used
